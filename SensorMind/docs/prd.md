# 需求文档

## 1. 应用概述

**应用名称**：SensorMind

**应用描述**：面向物联网工程学生的智能设备选型助手Web应用。用户通过选择场景和回答AI问题，或自由描述需求，获得个性化的IoT设备选型方案、预算清单和接线拓扑建议。

**品牌标识**：
- 品牌名：SensorMind
- Slogan：让硬件选型变简单

**技术能力**：使用minimax-m3技能实现AI对话和方案生成功能。

---

## 2. 用户与使用场景

**目标用户**：
- 物联网/电子/自动化专业学生
- DIY爱好者
- 小型项目开发者

**核心使用场景**：
- 桌面端/移动端浏览器访问
- 课程设计硬件选型
- 竞赛准备设备规划
- 个人项目立项前的硬件方案制定

---

## 3. 页面结构与功能说明

### 3.1 页面层级结构

```
├── 首页
├── AI对话页
├── 方案结果页
├── 代码建议页
└── 我的方案页
```

### 3.2 页面功能说明

#### 3.2.1 首页

**页面结构**：

1. **顶部品牌区**：
   - 大字标题：SensorMind
   - 副标题：让硬件选型变简单
   - 小字说明：AI驱动的物联网设备选型助手

2. **顶部导航栏**：
   - 我的方案入口

3. **快捷场景区**：
   - 5个场景卡片：宿舍智能、智慧农业、实验室监测、工业巡检、自由定制
   - 桌面端：横向排列
   - 移动端：两列网格布局
   - 卡片样式：浅灰底色、圆角、hover时上浮+阴影效果

4. **分隔区**：
   - 文字：或自由描述需求

5. **自由输入区**：
   - 输入框：占位符文字「例如：我想用太阳能做个水质监测站，预算500元，数据传到手机」
   - 开始选型按钮：蓝色渐变背景、白色文字、圆角

6. **底部统计**：
   - 小字：已生成 1247 份方案（静态数字）

**交互行为**：
- 点击快捷场景卡片：进入引导式问卷模式，跳转至AI对话页
- 在自由输入区输入内容后点击「开始选型」按钮：进入自由输入模式，跳转至AI对话页
- 点击顶部导航栏「我的方案」：跳转至我的方案页

#### 3.2.2 AI对话页

**页面布局**：
- 左侧：显示当前选择的场景图标（引导式问卷模式）或自由输入标识（自由输入模式）
- 右侧：对话区域

**引导式问卷模式**（点击快捷场景卡片进入）：

AI依次询问以下问题，每个问题提供快捷选项按钮：
1. 项目预算范围
2. 传感器精度要求
3. 通信方式偏好（有线/蓝牙/WiFi/LoRa）
4. 供电方式

用户点击选项后，AI继续下一个问题。完成所有问题后，跳转至方案结果页。

**自由输入模式**（自由输入区进入）：

1. AI先解析用户输入的约束条件（场景、传感器类型、预算、通信方式、供电方式）
2. 若存在缺失信息，AI最多追问2轮，每轮针对缺失项提问
3. 若检测到冲突（如预算与设备需求矛盾），执行冲突检测规则
4. 确认所有信息后，跳转至方案结果页

**基于此修改模式**（从我的方案页进入）：

1. 带入原方案的约束条件（场景、传感器类型、预算、通信方式、供电方式）
2. 用户可追加修改指令（例如换成电池供电、预算砍到200等）
3. AI解析修改指令，更新约束条件
4. 确认后，跳转至方案结果页

**交互形式**：
- 对话区采用聊天气泡形式
- 用户选项以圆角按钮呈现

#### 3.2.3 方案结果页

**页面内容**（纯文本格式）：

```
【设备清单】
设备名称 | 推荐型号 | 数量 | 参考单价 | 用途说明

【预算汇总】
总预算：XXX元

【连接拓扑】
ASCII拓扑图（按绘制规则生成）

【风险提示】
（如有）

【代码框架】
Arduino/MicroPython初始化代码框架
关键库名称
引脚定义建议
```

**交互功能**：
- 提供「保存方案」按钮（蓝色主按钮），点击后保存当前方案到历史记录
- 提供「重新生成」按钮（白色边框次要按钮），点击后返回AI对话页重新生成方案
- 保存成功时显示提示动画

#### 3.2.4 代码建议页

**页面内容**：
- Arduino/MicroPython初始化代码框架
- 关键库名称
- 引脚定义建议

#### 3.2.5 我的方案页

**页面功能**：
- 展示用户保存的历史方案列表，采用卡片式布局
- 每张卡片显示：方案名称（可编辑）、场景标签、总预算、保存时间
- 点击卡片，查看该方案的完整内容（设备清单、预算汇总、连接拓扑、风险提示、代码框架）
- 每张卡片增加「基于此修改」按钮，点击后跳转至AI对话页，带入原方案约束条件，用户可追加修改指令

## 4. 业务规则与逻辑

### 4.1 双入口交互逻辑

**引导式问卷模式**：
- 用户在首页点击快捷场景卡片
- 进入AI对话页，AI依次询问项目预算范围、传感器精度要求、通信方式偏好、供电方式
- 每步提供选项按钮供用户选择
- 完成所有问题后，生成方案并跳转至方案结果页

**自由输入模式**：
- 用户在首页自由输入区输入需求描述，点击「开始选型」按钮
- 进入AI对话页，AI解析用户输入的约束条件（场景、传感器类型、预算、通信方式、供电方式）
- 若存在缺失信息，AI最多追问2轮，每轮针对缺失项提问
- 若检测到冲突，执行冲突检测规则
- 确认所有信息后，生成方案并跳转至方案结果页

**基于此修改模式**：
- 用户在我的方案页点击某方案的「基于此修改」按钮
- 跳转至AI对话页，带入原方案的约束条件
- 用户追加修改指令（例如换成电池供电、预算砍到200等）
- AI解析修改指令，更新约束条件
- 确认后，生成新方案并跳转至方案结果页

### 4.2 冲突检测规则

当AI检测到用户输入的约束条件存在冲突时（如预算过低无法满足设备需求、通信方式与场景不匹配等），AI需：
1. 明确指出冲突点
2. 提供调整建议（如提高预算、更换通信方式）
3. 询问用户是否接受调整方案

### 4.3 方案生成逻辑

- 无论引导式问卷模式、自由输入模式还是基于此修改模式，最终输出相同纯文本格式方案
- 方案内容包括：设备清单、预算汇总、连接拓扑、风险提示、代码框架
- 设备清单数据由AI根据场景和约束条件实时生成，无需预设数据库
- 调用minimax-m3技能实时生成方案内容

### 4.4 连接拓扑图绘制规则

在【连接拓扑】模块中，按以下规则生成ASCII图：

**绘制规范**：
- 主控板放在顶部中央
- 传感器和模块挂在主控下方，用竖线连接
- 标注每个设备使用的GPIO接口和通信协议
- 电源单独从左侧或右侧标注
- 如果多个设备共用I2C总线，标注各自地址
- 如有冲突（地址重复或接口不足），在图旁加警告提示

**ASCII图示例模板**：

```
         5V2A适配器
             |
     +-------+-------+
     | ESP32WROOM32  |
     | 3.3V稳压       |
     | GPIO21SDA +---+---+---+
     | GPIO22SCL +---+---+   |
     +-----------+   |   |   |
             |       |   |   |
             |    DHT22  BH1750
             |    单总线   I2C地址0x23
             |
     GPIO25 +---> 继电器模块 ---> 风扇
     GPIO26 +---> 继电器模块 ---> 加湿器
```

**字符约束**：图中只使用以下字符：加号、减号、竖线、斜线、大于号、小于号、方括号、圆括号、字母、数字、汉字。禁止使用emoji、反引号、井号、星号等任何特殊符号。

### 4.5 方案保存与历史记录

- 用户在方案结果页点击「保存方案」，将当前方案存储至后端数据库
- 保存内容包括：方案ID、方案名称、场景标签、设备清单文本、拓扑图文本、预算明细、代码框架、保存时间戳
- 用户在「我的方案页」可查看所有历史方案
- 用户可编辑方案名称
- 用户可点击「基于此修改」按钮，带入原方案约束条件进行修改

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 用户未完成AI对话流程即退出 | 不保存任何数据，下次进入重新开始 |
| AI生成方案失败 | 提示用户「方案生成失败，请重试」，允许返回重新回答问题 |
| 保存方案失败 | 提示用户「保存失败，请稍后重试」 |
| 我的方案页无历史记录 | 显示「暂无保存的方案」提示 |
| 自由输入模式下用户输入为空 | 提示用户「请输入需求描述」，禁止提交 |
| 自由输入模式下AI追问2轮后仍缺失关键信息 | 提示用户「信息不足，无法生成方案」，允许返回重新输入 |
| 冲突检测后用户拒绝调整方案 | 提示用户「无法生成方案」，允许返回重新输入 |
| 拓扑图生成时检测到接口冲突或地址重复 | 在拓扑图旁加警告提示，说明冲突原因 |
| 用户编辑方案名称为空 | 提示用户「方案名称不能为空」，禁止保存 |
| 基于此修改模式下用户未输入修改指令 | 提示用户「请输入修改指令」，禁止提交 |

## 7. 验收标准

1. 用户打开应用，进入首页，看到顶部品牌区（大字标题SensorMind、副标题、小字说明）、顶部导航栏（我的方案入口）、快捷场景区（5个场景卡片）、分隔区（或自由描述需求）、自由输入区（输入框+开始选型按钮）、底部统计（已生成1247份方案）
2. 用户点击「宿舍智能」场景卡片，跳转至AI对话页，左侧显示场景图标，AI依次询问项目预算范围、传感器精度要求、通信方式偏好、供电方式，用户通过点击选项按钮完成回答
3. 完成所有问题后，跳转至方案结果页，显示纯文本格式方案（设备清单、预算汇总、连接拓扑ASCII图、风险提示、代码框架），底部显示「保存方案」按钮（蓝色主按钮）和「重新生成」按钮（白色边框次要按钮）
4. 用户点击「保存方案」按钮，显示成功提示动画，方案保存至历史记录
5. 用户点击顶部导航栏「我的方案」，进入我的方案页，看到刚才保存的方案卡片（显示方案名称、场景标签、总预算、保存时间），点击卡片查看完整方案内容
6. 用户点击该方案卡片的「基于此修改」按钮，跳转至AI对话页，带入原方案约束条件，用户输入修改指令「预算砍到200元」，AI解析后生成新方案并跳转至方案结果页
